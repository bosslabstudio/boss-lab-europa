# Boss Lab Europa

Static multilingual guide site for **Boss Lab: Robot Battle Builder** (Android), written by the developer, Boss Lab Studio. Art and audio are AI-assisted.

Served at https://bosslabstudio.github.io/boss-lab-europa/ (GitHub Pages, deploy from branch root). Plain HTML + inline CSS, no JS, no build step.

- Official site: https://www.bosslab.xyz/
- Google Play: https://play.google.com/store/apps/details?id=com.bosslab.game

Pages: ES, PT-BR, DE, RU, TR, IT, PL (see index.html).
